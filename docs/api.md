# API

Interactive documentation is available at `/docs`. Main routes: `/api/health`, `/api/profils`, `/api/ontology/{classes,properties,individuals,stats}`, `/api/ontology/class/{id}`, `/api/contraceptifs`, `/api/search`, `/api/search/semantic`, and `/api/ask`.

The application is an academic knowledge-engineering system. It does not diagnose, prescribe, or generate personalized contraceptive recommendations.
